# Synora — Current Status

Synora currently has one core product feature: **Task Marketplace**.

Supporting systems:
- verified DIU Google authentication;
- task-only private messaging;
- profile/account details;
- ratings;
- moderation and reporting;
- admin controls.

Removed from current product scope:
- Team Match / Opportunity Network;
- Borrow Hub;
- credits;
- Campus Directory;
- shops/hotels/business listings and reviews.

Production hardening is in progress on the `production-hardening` branch. The known pre-hardening checkpoint is `b7e9fac`.
