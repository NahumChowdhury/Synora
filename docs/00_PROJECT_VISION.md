# Synora — Project Vision

## Project Name

Synora

---

# Vision

Synora is a university-exclusive collaboration platform designed to help students connect, earn, share resources, and improve campus life through one secure ecosystem.

Unlike traditional social media, Synora focuses on solving real student problems by combining freelancing, borrowing, networking, and campus reviews into a single platform.

The long-term goal is to become the digital hub for university students.

---

# Target Users

Initially:

* Daffodil International University (DIU) students

Future expansion:

* Other universities in Bangladesh

---

# Core Objectives

Synora should help students:

* Earn money by completing tasks.
* Borrow and lend useful items.
* Find teammates and opportunities.
* Share honest campus experiences.
* Build a trusted student community.

---

# Core Modules

1. Task Marketplace
2. Borrow Hub
3. Opportunity Network
4. Campus Guide

Each module must be designed as part of one unified ecosystem rather than four separate applications.

---

# Long-Term Philosophy

Every feature added to Synora must satisfy at least one of these goals:

* Save students time.
* Help students earn.
* Improve collaboration.
* Increase trust within the campus community.
* Make university life easier.

If a future feature does not support these goals, it should not be added.

---

# Development Principles

* Build a stable foundation before adding new features.
* Security is more important than speed.
* User experience should remain simple and intuitive.
* Documentation must stay synchronized with development.
* Every completed milestone should update PROJECT_STATUS before being committed.
