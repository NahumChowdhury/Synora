# Synora Project Vision

Synora is a focused DIU student **Task Marketplace**.

A verified DIU Google account establishes account ownership. Students can post a task or apply to complete one. Within task flows, public identity is deliberately anonymous: DIU email, profile name, and global user ID must not be exposed as the participant label.

The product should stay intentionally narrow. Authentication, messaging, ratings, profile/account details, moderation, and administration exist only to support the Task Marketplace.

Removed product areas must not be reintroduced without a deliberate product decision. This includes Team Match / Opportunity Network, Borrow Hub, credits, Campus Directory, shops, hotels, and business listings/reviews.
