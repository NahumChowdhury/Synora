# Feature Specifications

## Task Marketplace
A Task can include title, description, category, requirements, deadline, budget, and status.

Supported categories include PPT, assignment, presentation, thesis, design, coding, research, and other.

Users can:
- browse/search/filter tasks;
- post a task;
- apply once to another student's open task;
- include an optional application message;
- review applicants if they are the requester;
- select one worker;
- coordinate in a participant-only task conversation;
- advance through the valid task lifecycle;
- cancel where backend rules allow;
- rate the other participant after completion within the rating window.

Task-facing participant identity must remain anonymous. Requester and worker labels are contextual rather than global identities.

## Messaging
A task conversation is created only after a requester selects a worker. Only the two participants can access it. Messages persist, support block/unblock and reporting, and are subject to content-safety checks.

## Profile
Editable account/profile fields may include full name, department, batch, skills, and bio. Verified DIU email is read-only. These fields are account/profile details and are not exposed as Task identities.

## Administration
- user listing;
- ban/unban;
- Task Marketplace enable/disable setting;
- message report review.
