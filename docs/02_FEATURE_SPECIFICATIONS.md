# Synora — Feature Specifications

## Purpose

This document describes every core module of Synora in detail.

Business logic, workflows, and future implementation must follow these specifications.

---

# Module 1 — Task Marketplace

## Objective

Allow students to hire other students for academic or creative tasks.

## Example Tasks

* PowerPoint Presentation
* Assignment Writing
* Research Assistance
* Lab Report
* Poster Design
* CV Design
* Graphic Design
* Video Editing
* Photo Editing
* Programming Tasks

## Workflow

1. User creates a task.
2. Students browse available tasks.
3. Interested workers apply.
4. Task owner reviews applicants.
5. One worker is selected.
6. Task is completed.
7. Payment is made (COD initially).
8. Both users submit ratings.
9. Task is archived.

## Future Enhancements

* Deadline reminders
* File attachments
* Chat system
* Online payments
* Escrow system

---

# Module 2 — Borrow Hub

## Objective

Help students borrow and lend useful campus items.

## Supported Items

* Books
* Calculators
* Laptops
* Chargers
* Lab Equipment
* Stationery
* Other approved items

## Workflow

1. Owner lists an item.
2. Borrower requests it.
3. Owner accepts or rejects.
4. Credit deducted.
5. Item returned.
6. Credits updated.
7. Transaction stored.

## Future Enhancements

* Due-date reminders
* Late return penalties
* QR verification
* Damage reporting

---

# Module 3 — Opportunity Network

## Objective

Connect students with opportunities.

## Categories

* Project Team
* Startup Partner
* Club Recruitment
* Hackathon Team
* Travel Partner
* Study Partner

## Workflow

1. User creates an opportunity.
2. Other students browse listings.
3. Interested users apply.
4. Creator accepts suitable members.
5. Opportunity closes.

## Future Enhancements

* Skill matching
* AI recommendations
* Resume upload
* Portfolio links

---

# Module 4 — Campus Guide

## Objective

Provide trustworthy campus information through student reviews.

## Review Categories

* Cafeterias
* Restaurants
* Hotels
* Shops
* Clubs
* Teachers (future)
* Campus Facilities
* Study Resources

## Workflow

1. Admin creates listings.
2. Students submit reviews.
3. Ratings are calculated.
4. Admin moderates reports.

## Future Enhancements

* Photo uploads
* Maps integration
* Trending places
* Search and filters

---

# Future Modules (Not Yet Planned)

These ideas may be explored after the four core modules are complete.

Examples:

* Marketplace for used items
* Campus events
* Lost & Found
* Internship Board
* Scholarship Portal

These are intentionally postponed until the core platform is stable.

---

# Development Priority

The implementation order should be:

1. Authentication
2. Task Marketplace
3. Borrow Hub
4. Opportunity Network
5. Campus Guide

No future module should delay completion of the core modules.
