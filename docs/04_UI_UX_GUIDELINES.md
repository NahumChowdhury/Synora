# UI / UX Guidelines

## Visual direction
- Light SaaS/product interface.
- Off-white/light slate background, white cards, subtle borders and shadows.
- Dark navy/charcoal typography with professional emerald/blue accents.
- No neon/glowing visual treatment.
- No stock people photography.
- Keep the product focused and hand-crafted rather than crowded with modules.

## Terminology
Use **Login**, **Register**, **Task Marketplace**, **Messages**, **Profile**, and **Admin Panel** consistently.

Do not show Team Match / Opportunity Network terminology.

## Task identity
Task UI must not reveal participant DIU email, profile name, or global user ID. Use contextual aliases such as Requester / Selected Worker or task-specific anonymous labels.

## States
Every core screen should handle loading, empty, success, validation, permission, feature-disabled, and server-error states without looking broken.
